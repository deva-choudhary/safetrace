# SafeTrace

**Women Safety Incident Reporting & Analytics Platform**

## About the Project

SafeTrace is a web application designed to help users report safety incidents and help administrators analyze incident data through a dashboard.

## Planned Features

- User registration and login
- Safety incident reporting
- Incident status tracking
- Admin dashboard for managing reports
- Analytics and charts
- Location-based incident visualization

## Technology Stack

The planned technologies include React, Node.js, Express.js, PostgreSQL, and Git/GitHub.

## Project Status

Currently in the initial setup and planning stage.

## Purpose

This project is a learning implementation inspired by the Smart India Hackathon problem statement SIH1605 on women's safety analytics.
